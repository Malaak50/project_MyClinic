# Prérequis Système
- Installer Node.js LTS (>=18) depuis nodejs.org
- Installer Expo (CLI moderne) avec: `npm`
- Installer Git (optionnel pour versionnement)
- Créer un compte Firebase et un projet i -g expo@latest
- Avoir un éditeur (VS Code) et un émulateur ou Expo Go sur mobile

## Vérifications
- `node -v` affiche une version >= 18
- `npm -v` fonctionne
- `expo -V` fonctionne
