# Configuration Firebase (Auth + Firestore)

## Création du projet
1. Aller sur console.firebase.google.com, créer un projet
2. Activer Authentication (Email/Password)
3. Activer Firestore (mode production)

## Config Web (Frontend)
Récupérer la config Web et la mettre en variables:
- `EXPO_PUBLIC_FIREBASE_API_KEY`
- `EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN`
- `EXPO_PUBLIC_FIREBASE_PROJECT_ID`
- `EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET`
- `EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID`
- `EXPO_PUBLIC_FIREBASE_APP_ID`

## Service Account (Backend)
1. Aller dans Paramètres du projet > Comptes de service
2. Générer une clé JSON et la sauvegarder
3. Définir `GOOGLE_APPLICATION_CREDENTIALS` vers ce fichier
4. Définir `FIREBASE_PROJECT_ID`

## Collections Firestore
Créer les collections:
- `users` (uid, role, email, displayName, phone, createdAt)
- `doctors` (id=uid, specialties[], clinicName, availability[], status)
- `patients` (id=uid, birthDate, allergies[], chronicConditions[], insuranceNumber)
- `appointments` (patientId, doctorId, status, scheduledAt, reason, notes)
- `medicalRecords` (patientId, doctorId, entries[], lastUpdated)
- `prescriptions` (patientId, doctorId, items[], issuedAt, expiresAt)
- `notifications` (userId, type, title, body, createdAt, read)

## Règles de Sécurité (exemple)
- Admin: interdit sur `medicalRecords`, `prescriptions`
- Patient: accès restreint à ses documents
- Doctor: accès aux patients liés par RDV confirmé

Définir les règles via Firebase Console (adapter selon vos besoins).
